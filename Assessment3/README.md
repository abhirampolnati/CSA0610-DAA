## 1. Introduction

This assessment focuses on the design, implementation, and analysis of various algorithms using Divide and Conquer and other advanced algorithmic techniques.

The objective is to understand how different algorithmic approaches solve computational problems, compare their efficiency, and analyse their time and space complexities.

The assessment includes mathematical analysis, algorithm implementation, testing, and performance evaluation.

## 2. Objectives

- Understand the Divide and Conquer approach.
- Implement different algorithmic techniques.
- Analyse best-case, average-case, and worst-case complexities.
- Compare conventional and optimized algorithms.
- Evaluate algorithm performance using test cases.
- Understand the relationship between theoretical and experimental results.

## 3. Algorithms Covered

### Q1 – Basic Divide and Conquer
- Maximum and Minimum using Divide and Conquer.
- Binary Search.

### Q2 – Sorting Algorithms
- Merge Sort.
- Quick Sort using the Last Element as Pivot.

### Q3 – Multiplication Algorithms
- Standard Multiplication.
- Karatsuba Multiplication.

### Q4 – Matrix Multiplication
- Conventional Matrix Multiplication.
- Strassen's Matrix Multiplication.

### Q5 – Closest Pair of Points
- Brute Force Approach.
- Divide and Conquer Approach.

### Q6 – Advanced Algorithmic Techniques
- Median of Medians.
- QuickSelect.
- Meet-in-the-Middle Subset Sum.

## 4. Methodology

The following methodology is adopted for each problem:

1. Understand and analyse the problem statement.
2. Identify the appropriate algorithmic approach.
3. Design the algorithm.
4. Analyse its time and space complexity.
5. Implement the algorithm.
6. Execute test cases with different input sizes.
7. Record execution time and experimental results.
8. Compare theoretical and practical performance.

## 6. Performance Analysis

The algorithms will be evaluated based on:

- Input size.
- Execution time.
- Time complexity.
- Auxiliary space complexity.
- Best, average, and worst-case performance.
- Comparison between different algorithmic approaches.

Experimental results will be recorded in CSV files and represented using graphs wherever applicable.

## 7. Testing

Each algorithm will be tested using suitable test cases, including:

- Small input datasets.
- Medium input datasets.
- Large input datasets.
- Boundary conditions.
- Special cases.
- Randomized inputs, wherever applicable.

The correctness of each implementation will be verified against expected results.
